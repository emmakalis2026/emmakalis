# emmakalis.pl

Nowa, uproszczona strona autorska Emmy Kalis.

## Publikacja na GitHub Pages

1. W repozytorium `emmakalis2026/emmakalis` usuń stare pliki strony, pozostawiając historię repozytorium.
2. Wgraj całą zawartość tej paczki do głównego katalogu repozytorium.
3. Sprawdź w `Settings → Pages`, czy źródłem jest gałąź `main` i katalog `/ (root)`.
4. W polu `Custom domain` powinno znajdować się `emmakalis.pl`.
5. Po prawidłowym połączeniu zaznacz `Enforce HTTPS`.
